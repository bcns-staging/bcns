Real rule bases aren't written IP-by-IP -- they're written zone-to-zone (Trust -> Untrust, Untrust -> DMZ, and so on). A rule scoped to one zone pair simply doesn't apply to traffic between a different pair, even if the source IP is identical and the destination is technically reachable.

The seeded traditional rule base has an "Allow Trust Outbound" rule scoped specifically to Trust -> Untrust. The same source host sending to a destination in the DMZ zone instead doesn't match that rule at all -- zone pairing, not just IP connectivity, decides.
