A firewall's rule base (also called an ACL or security policy) is an ordered list. Each rule specifies zones, IPs, and a service, plus an action. Traffic is checked against the list top to bottom, and the first rule that matches wins -- every rule after it is never even considered for that connection. If nothing matches, an implicit deny at the very bottom drops the traffic.

This ordering dependency is the single most common source of firewall misconfiguration -- a broad rule placed too early silently swallows every narrower rule below it. See Shadowed & Redundant Rules for exactly that failure mode.
