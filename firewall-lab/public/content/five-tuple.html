The original firewall model -- a packet filter -- decides using exactly five fields, together called the 5-tuple: protocol, source IP, source port, destination IP, destination port. Nothing else about the traffic matters to it -- not what application generated it, not who's logged in, not what's inside the payload.

The 5-tuple
Protocol
tcp / udp / icmp
Source IP
Source port
Dest. IP
Dest. port
→
allow / deny

This is still exactly what every firewall's fast path uses for already-established connections (see Stateful Inspection) -- the 5-tuple never went away, NGFW just adds more fields on top of it for the first packet of a new connection.
