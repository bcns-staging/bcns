A firewall is a single point of failure by design -- every packet has to pass through it. Production deployments run an active/passive HA pair: a standby node continuously mirrors the active node's configuration and, via a heartbeat, takes over immediately if the active node fails.

Configuration syncs easily. Session state is the harder problem: without session synchronization, the standby node has no idea which connections were already open when it suddenly becomes active -- every in-flight connection looks like unexpected, unmatched return traffic and gets dropped, even though the security policy would have allowed it. With sync enabled, the standby already has a live copy of the session table and failover is seamless.
