A site-to-site VPN links two networks over the public internet as if they were directly connected, using IPSec to encrypt everything in between. Setting one up has two phases:

  • Phase 1 (IKE) -- the two firewalls authenticate each other and negotiate a secure channel used only to set up Phase 2.
  • Phase 2 (IPSec SA) -- the actual encryption parameters for the data itself, plus the proxy-IDs / remote domain: which specific subnets on each side are allowed to talk through this tunnel.

That remote domain is what decides routing: traffic destined for an address inside it gets encrypted and sent through the tunnel; everything else takes the normal default path.
