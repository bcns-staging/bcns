Intrusion Prevention (IPS) inspects content for known exploit patterns -- the network equivalent of antivirus signatures, but for the attack traffic itself rather than files. A signature matches a specific, known vulnerability (usually tied to a CVE), and the action is typically more aggressive than a plain block: a TCP reset tears down the connection immediately rather than just silently dropping packets.

Real IPS engines do far more than string matching -- protocol decoders, normalization, evasion handling -- but the core idea is the same one this lab's tiny signature set demonstrates.
