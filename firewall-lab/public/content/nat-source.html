Internal hosts almost always use private (RFC1918) addresses that aren't routable on the internet. Source NAT rewrites the source address as traffic leaves the firewall so the rest of the world can reply to it.

  • Dynamic PAT ("masquerade") -- every internal host sharing a single public IP, distinguished by port number. This is what almost every home router and most enterprise egress does.
  • Static NAT -- a fixed 1:1 mapping between one internal IP and one public IP, used when a specific internal host needs a consistent, predictable public identity (e.g. a server that itself makes outbound connections others need to recognize).
