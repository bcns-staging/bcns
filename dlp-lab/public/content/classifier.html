Every technique so far looks for something specific: a pattern, a keyword, a known record, a known document. Statistical classification takes a fundamentally different approach: it learns, from examples, which words tend to co-occur with "sensitive" content in general, and scores new text by probability -- without needing to know in advance what specific words will appear.

Naive Bayes, briefly

This lab trains a real (deliberately small) Naive Bayes classifier: for each class ("sensitive" / "not-sensitive"), it counts how often each word appears across all training examples of that class. To classify new text, it multiplies together the probability of each word appearing given each class (using Laplace smoothing so unseen words don't zero out the whole calculation), and picks whichever class comes out more probable.

This is "naive" because it assumes each word's presence is independent of the others, which isn't really true of language -- but it's a surprisingly effective, fast, and interpretable baseline, and it's genuinely how early spam filters (and some DLP content classifiers) worked. Watch the "most indicative words" for each class update as you add more examples -- that's the model's actual learned state, not a black box.
