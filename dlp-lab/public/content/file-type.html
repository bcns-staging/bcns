File extensions are just a suggestion -- anyone can rename malware.exe to invoice.pdf and most naive systems will treat it accordingly. Every real file format instead begins with a distinctive sequence of bytes called a magic number (PDFs start with %PDF, PNGs with a fixed 8-byte signature, Windows executables with MZ). Reading those first few bytes tells you what a file actually is, independent of its name.

This is the first thing most antivirus engines and DLP file inspectors do before deciding whether to bother with deeper (and more expensive) inspection.
