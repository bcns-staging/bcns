Every DLP technique so far has been about data in motion -- something happening right now (a send, an upload, a copy). Data at rest is different: files that have been sitting on a network share or in cloud storage for months, possibly never scanned when they were first created, possibly containing sensitive data nobody flagged at the time.

Real DLP programs run periodic discovery scans across storage to catch exactly this -- old exports, forgotten backups, a spreadsheet someone saved to a shared drive years ago. This page models that: populate a virtual file share (each file carries a sensitivity label, just like a real document management system), then run a scan and watch policies evaluate every file at once.
