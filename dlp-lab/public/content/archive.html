A zip file is opaque to every text-based detector until something actually opens it. Real DLP content inspectors unpack archives (including office documents, which are just zip files internally) and run the same detection pipeline against every file inside -- recursively, since a zip can contain another zip.

This obviously can't go on forever: a maliciously crafted archive can expand to gigabytes from a tiny file (a "zip bomb"), so this lab caps recursion depth, entry count, and total extracted bytes, exactly like a production content inspector would.
