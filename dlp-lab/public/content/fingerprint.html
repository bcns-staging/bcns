Document/Indexed Document Matching (IDM) answers a question EDM can't: "does this content contain a piece of one of our confidential documents," even if it's just a paragraph pasted into an email, not the whole file.

How it works: shingling

The reference document is broken into overlapping chunks of a fixed number of words (a technique called shingling) -- this lab uses 8-word windows sliding one word at a time. Each chunk is hashed. That produces a "fingerprint": a set of hashes representing every 8-word sequence in the document.

Shingling, simplified to a 3-word window (the lab uses 8)
thequickbrownfoxjumps →hash 0x9f2a…
thequickbrownfoxjumps →hash 0x51c4…
thequickbrownfoxjumps →hash 0x7de0…

Every sliding window becomes one hash. The full hash set is the document's fingerprint; a scan counts how many of those hashes reappear in new content.

To check new content, the same shingling process runs over it, and the lab counts what fraction of the original document's chunks reappear. Copy even a few sentences into an otherwise unrelated document, and a meaningful percentage of the reference fingerprint will show up -- generally without needing to store or compare the raw document text at scan time.

This is conceptually the same idea (much simplified) behind techniques like MinHash and the document fingerprinting features in commercial DLP and plagiarism-detection tools alike.
