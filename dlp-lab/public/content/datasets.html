Almost every advanced DLP technique needs a source of truth to compare against: a list of forbidden phrases, a set of known-sensitive records, or a reference document you don't want copied elsewhere. This page is where you define all three -- everything else in the lab reads from here.

  • Keyword lists feed the Keyword & Proximity detector directly.
  • EDM record sets feed the Exact Data Match detector -- your raw values are only ever turned into salted hashes at match time, never compared or stored in plaintext, which is exactly how production EDM systems avoid becoming a new source of the very leak they're meant to prevent.
  • Reference documents feed the Document Fingerprinting detector, which can recognize a paragraph lifted from one of these documents even if the rest of the surrounding text is completely different.
