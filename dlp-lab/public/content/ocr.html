A screenshot of a spreadsheet full of SSNs is, to every text-based detector, just an opaque image -- none of the pattern, keyword, EDM, or fingerprinting techniques can see inside it. Screenshotting sensitive data to get around a text-based DLP filter is a real, common evasion technique. OCR (Optical Character Recognition) closes that gap by extracting whatever text is visible in an image, which then flows through the exact same detectors as any other content.

This lab uses a real OCR engine (Tesseract, running as WebAssembly) -- not a simulation. The trade-off is a real one too: on first use, it needs to download its trained language model over the network (a few megabytes), which is then cached locally for every run after that.
