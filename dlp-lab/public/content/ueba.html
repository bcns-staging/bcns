Every technique so far inspects a single event in isolation: is this message, this file, this upload sensitive? UEBA (User & Entity Behavior Analytics) asks a different question entirely: is this behavior normal for this person? A single file upload that contains no detectable sensitive content at all can still be part of a slow, deliberate exfiltration -- or a compromised account suddenly moving far more data than usual.

How this lab's baseline works

For each user, a rolling average of past event sizes acts as a personal baseline. A new event is compared against it as a ratio -- this lab flags anything 3x or more above baseline as anomalous. Real systems build far richer baselines (time of day, peer group norms, typical destinations), but the core mechanic -- compare against a person's own normal, not a global threshold -- is the same idea that makes UEBA catch things content-based detection structurally cannot.
