Real attachment sandboxing detonates a file in an isolated virtual machine and watches what it actually does -- does it spawn a shell, reach out to a command-and-control server, encrypt files? That requires real execution infrastructure this local lab intentionally does not provide (running arbitrary uploaded files would defeat the entire point of a safe learning environment).
