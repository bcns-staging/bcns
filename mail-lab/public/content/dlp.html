Data Loss Prevention (DLP) scans outbound mail -- content your own organization is about to send -- for patterns that look like sensitive data, and blocks or redacts it before it leaves. This protects against accidental leaks (pasting the wrong spreadsheet) as much as intentional exfiltration.

This lab checks for a few classic, still extremely common patterns:

  • US Social Security Numbers (123-45-6789 format)
  • Credit card numbers -- validated with the Luhn algorithm so random 16-digit numbers don't false-positive as often
  • Cloud provider API keys (AWS access key IDs, generic sk-/pk- style secret prefixes)

Real DLP systems add far more pattern types (passport numbers, health record identifiers, custom regex per organization) and often score contextual signals rather than matching patterns alone -- but the core mechanism is the same one shown here.
